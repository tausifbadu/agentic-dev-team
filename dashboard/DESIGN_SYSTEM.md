# Dashboard Design System

Generated by the **UI/UX Pro Max** skill (`nextlevelbuilder/ui-ux-pro-max-skill`)
for product type: *dark-mode developer dashboard for an agentic AI dev team —
real-time agent monitoring and logs*. This is the source of truth for the
dashboard's look & feel. Tokens live in `frontend/tailwind.config.js`.

## Style
**Dark Mode (OLED)** — deep midnight base, high contrast, smooth transitions.
Dark-only. Targets WCAG AAA where practical.

### Status palette (distinct from the green accent)
- success `#10B981` / text `#34D399`
- warning `#F59E0B` / text `#FBBF24`
- danger  `#EF4444` / text `#F87171`
- info    `#3B82F6` / text `#60A5FA`
- neutral slate

> Accent green = interactive / brand / "run". Status green = "passed / success".
> Kept as separate tokens so a primary button never visually merges with a
> "passed" badge.

## Typography
- **Inter** for headings and body (already in use).
- Base 16px, line-height 1.5, semantic tokens — no raw hex in components.

## Effects
Minimal glow, dark→light hover transitions (150–300ms), low white emission,
visible focus rings, defined card elevation.

## Pre-delivery checklist (enforced)
- [ ] SVG icons only (Heroicons/Lucide) — no emoji as icons
- [ ] `cursor-pointer` on all clickable elements
- [ ] Hover states with smooth 150–300ms transitions
- [ ] Text contrast ≥ 4.5:1
- [ ] Visible focus states for keyboard nav (`focus-visible`)
- [ ] `prefers-reduced-motion` respected
- [ ] Responsive: 375 / 768 / 1024 / 1440 px
